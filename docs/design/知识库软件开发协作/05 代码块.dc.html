同步引擎

核心是一个 CRDT 合并函数,离线改动进入 outbox,联网后按因果序回放:

Future<void> flushOutbox() async {
  final ops = outbox.drain();
  // 按因果序回放,冲突交给 CRDT 合并
  for (final op in ops) {
    await doc.apply(op);
  }
}
