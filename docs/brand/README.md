# 品牌标志(Brand mark)

## 这个标志是什么

**字母 M**,两笔内侧切开,读作折叠的层片 —— 云母(mica)这个矿物意象。

2026-09-02 取代了「等轴测立方体线框 + 顶点图谱节点」(那一版活了五天),后者又取代了
更早的「三层菱形」。

换掉上一版的理由只有一条,而且是量出来的:**它在小尺寸上读不出来**。把它和 ChatGPT、
Claude 的图标并排放进同一条任务栏,问题不是"能不能看见",是"**认不认得出**" ——
六边形 + 六个角节点 + 三条辐条 + 中心点,十个元素挤在 40 像素里,合成的是纹理不是图形。
16px 的托盘格子里更彻底,只剩一颗没有轮廓的蓝点。

M 没有这个问题:16px 上轮廓和中间那个 V 形缺口都还在(实测四档,见下)。

## 一份源,四个出口

| 出口 | 文件 | 怎么来的 |
| --- | --- | --- |
| **源** | `assets/mica-logo.svg` | 1024×1024 矢量,透明底 |
| 应用内(登录页 / About) | `assets/logo_mark.png` → `lib/widgets/mica_logo.dart` | golden 测试从 SVG 光栅出的 512 |
| 任务栏 / exe | `windows/runner/resources/app_icon.ico` | 七帧,各自从 SVG 光栅后打包 |
| 系统托盘 | `assets/tray_icon.ico` | 同上,与上一行**字节相同** |
| 浏览器标签 | `web/favicon.svg` | 源 SVG 的**逐字节拷贝** |

**为什么托盘要单独一个文件**:`tray_manager` 收的是 Flutter asset 路径,拿不到
`windows/runner/resources/` 里的东西,磁盘上必须有第二份。**这正是它烂掉的原因** ——
2026-07-20 到 2026-08-28 之间应用图标换过一次、托盘那份没跟着换,托盘一直显示
**Flutter 脚手架自带的官方 logo**,一个多月没人发现。现在 `scripts/release-check.sh`
在两个文件不一致时**拒绝发版**。

**为什么 favicon 只能是拷贝**:标签页图标必须在 Flutter 启动之前就存在,没法由应用生成。
但它不再是"照着公式手工重画"(上一版是),而是 `cp` —— 拷贝可以被机器检查,重画不能。
`test/mica_logo_test.dart` 比对两者,不一致就红。

## 改动流程

改 `assets/mica-logo.svg`,然后跑 `assets/README.md` 里那三条命令。**忘了跑会怎样**:
`test/icon_export_test.dart` 是 golden 测试,CI 当场红并附 diff 图。

## 没有尺寸变体了

上一版是「一个设计,两个光学尺寸」:≥128px 画晶体位图,以下改画简化线框,painter 内部
96px 处还有第二道分档。**2026-09-02 三档全删。**

分档本身不是坏设计 —— 它是上一版为了在 16px 存活付出的代价。代价包括:两套几何要各自
维护、favicon 要照公式手算、以及一类没人看得见的 bug——某个尺寸悄悄拿到了另一枚标志。
新标志在 16px 上直接就成立,那么**为了它存在的机制就该跟着消失**,而不是留着"以后也许
用得上"。约 110 行几何随之删除。

## 颜色

渐变 `#4F7CFF` → `#6357E8` → `#8B4DE8`(蓝 → 靛 → 紫),左右两笔另有两道副渐变做折面。
深浅两种背景上都验过。

**不要靠模糊做层次**:图标链走 `flutter_svg`,它**静默丢弃 `<filter>`**。上一版靠两圈
高斯模糊做的核心辉光,在应用里从来就是硬边的。
