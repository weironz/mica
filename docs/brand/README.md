# 品牌标志(Brand mark)

## 这个标志是什么

**等轴测立方体的线框 + 顶点上的图谱节点** —— 装在晶体里的知识图谱。

2026-08-28 取代了原来的「三层菱形」。云母(mica)这个矿物意象仍在(晶体、透明、
层状),变的是这枚标志现在还说出了**产品在做什么**:节点和边,不只是层。

几何上它只有三件事:

1. 一个正六边形 —— 立方体在等轴测投影下的轮廓;
2. 从中心到**间隔的三个顶点**的三条辐条 —— 朝向观察者的那三条棱;
3. 顶点和中心的圆点 —— 图谱节点。

就这些。**简单是功能性的**:它要在系统托盘 16px 的格子里还能认出来,而设计稿里
那枚发光水晶(A1)在那个尺寸只会糊成一坨蓝色。

## 一份几何,四个出口

| 出口 | 文件 | 怎么来的 |
| --- | --- | --- |
| 应用内(登录页 / About) | `lib/widgets/mica_logo.dart` | **权威**,自绘 CustomPainter |
| 任务栏 / exe | `windows/runner/resources/app_icon.ico` | 由 painter 光栅化后打包 |
| 系统托盘 | `assets/tray_icon.ico` | 同上,与上一行**字节相同** |
| 浏览器标签 | `web/favicon.svg` | 手工镜像(见下) |

**为什么托盘要单独一个文件**:`tray_manager` 收的是 Flutter asset 路径,拿不到
`windows/runner/resources/` 里的东西,所以磁盘上必须有第二份拷贝。**这正是它烂掉的
原因** —— 2026-07-20 到 2026-08-28 之间,应用图标换过一次,托盘那份没跟着换,于是
托盘一直显示的是 **Flutter 脚手架自带的官方 logo**,一个多月没人发现。现在
`scripts/release-check.sh` 会在两个文件不一致时**拒绝发版**。

**favicon 为什么只能手工镜像**:标签页图标必须在 Flutter 启动之前就存在,所以它没法
由 painter 生成。SVG 顶部的注释里写着 painter 公式在 32×32 上的求值过程,改几何时
照着重算一遍。

## 改动流程

改 `lib/widgets/mica_logo.dart`,然后:

```bash
cd clients/mica_flutter
flutter test --update-goldens test/icon_export_test.dart   # 重新光栅化各尺寸
cd .. && python scripts/gen-icons.py                        # 打包两个 .ico
```

再按 SVG 注释里的公式更新 `web/favicon.svg`。

**忘了跑会怎样**:`test/icon_export_test.dart` 是 golden 测试 —— painter 变了而
没重新生成,CI 就红,并附上 diff 图。这比"记得跑脚本"可靠,上面那个一个多月没人发现的
bug 就是"靠记性"的产物。

## 尺寸变体(optical size)

**每个尺寸是各自的画,不是同一张图的缩放。** painter 在 22px 以下切到简化版:
去掉六个角节点、只留中心节点,描边相对加粗。

理由是实测出来的:按比例画的六个圆点落在 16px 的六边形上会把图形糊死(第一版就是
这样),而单纯把 256px 缩到 16px 是同一个结果。`.ico` 是个容器,本来就该每个尺寸放
不同的画。

## 颜色

渐变 `#2563EB` → `#7C3AED`(深蓝 → 紫),取自设计稿 A1 的色轴。

`MicaLogo(color: ...)` 传入单色则覆盖渐变 —— 深色背景上的托盘、单色印刷等场合用,
渐变在那些地方会读成一团脏色。
