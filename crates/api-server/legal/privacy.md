# 隐私声明

最后更新：2026-08-05

本页说明这个 Mica 实例实际收集、存储和传输哪些数据。内容按代码与本实例的实际配置写成，
不是通用模板——凡是本实例没做的事，下面会明说「没有」。

## 我们存什么

**账号**：邮箱、显示名、密码（以哈希形式存储，服务端任何时候都不持有明文）、创建与更新时间。
没有手机号、没有住址、没有画像标识。

**你的内容**：页面正文与其协同编辑历史存在本实例自己的数据库里；图片等附件存在本实例
自己的对象存储里。两者都不经过第三方内容服务。

**会话**：登录后签发的令牌，用于保持登录状态。

**日志**：结构化运行日志（请求路径、状态码、耗时一类），按 10 MB × 3 份轮转，滚完即弃。

## 我们不做什么

- **没有分析、没有埋点、没有 telemetry 回传。** 应用不会把使用行为发回任何地方。
- **诊断信息默认关闭**，是一个需要你主动打开的开关（opt-in），且只在本机使用。
- **没有广告，不向任何人出售或共享你的内容。**
- **本实例未配置 AI 服务商**，因此你的文档内容不会被发往任何模型服务。（产品支持接入 AI；
  一旦本实例接入，本页会写明发往何处、发送什么。）

## 数据会离开这台服务器的三种情况

1. **邮件**：注册验证与找回密码的邮件经阿里云邮件推送（DirectMail）发出，因此**你的邮箱地址**
   会到达该服务。邮件正文只含链接，不含你的文档内容。
2. **备份**：数据库与对象存储的备份**加密后**上传至阿里云对象存储（OSS）。加密密钥不在
   备份介质上。
3. **分享链接**：你主动创建的公开分享链接，**知道 URL 的任何人都能访问**，无需登录。撤销
   分享即失效。

除此之外，你的内容不出这台服务器。

## 你的控制权

- **导出**：随时导出整个工作区（Markdown + 图片的 zip）。
- **删除账号**：应用内提供账号删除。
- **回收站**：删除的页面进入回收站，**不会自动清空**，何时永久删除由你决定。

## 本实例的性质

这是一台**自托管的个人实例**，注册当前是关闭的。它由个人运营，不是商业服务，
**不提供可用性承诺**——具体见服务条款。
